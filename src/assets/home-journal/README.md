# Notebook home artwork

The three transparent PNGs were produced with the built-in `imagegen` tool from
the user-supplied reference screenshot on 2026-10-11. They are illustrations,
not screenshots of interactive controls. The SVG symbols are editable UI icons.

Prompt constraints used for each asset:

- `duck-banner.png`: Extract only the two large hand-drawn ducks at the top,
  preserving their notebook, flower, cushions, headphones and music notes. Place
  them side by side in a wide 3:1 transparent banner. Remove status icons, clock,
  numbers, text, calendar, avatar, cards and navigation. Keep white duck interiors
  opaque and the surrounding negative space genuinely transparent.
- `duck-avatar.png`: Extract the small round duck avatar to the left of the
  reference date. Preserve the helmet, pastel blue details, yellow bill and dark
  sketch outlines. Center it on a transparent square canvas without UI or text.
- `duck-astronaut.png`: Extract only the tiny duck astronaut above the reference
  add button. Preserve the blue helmet, hands and outlines. Remove the black
  button, plus sign, speech bubbles and all UI; use a transparent square canvas.

Interactive task data, date markers, badges and navigation are rendered by the
application and are never baked into these images.
